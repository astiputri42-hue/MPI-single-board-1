Tujuan Pembelajaran (TP)

  • Menerapkan 4 fondasi Berpikir Komputasional dalam merancang solusi berbasis sistem tertanam (embedded systems).
  • Menganalisis anatomi, fungsi pin GPIO, serta arsitektur hardware Single Board Computer Arduino Uno.

Indikator Ketercapaian (IKTP)

  • Mampu membedakan perbedaan mikrokontroler standalone dan Single Board Computer.

  • Mencapai nilai Evaluasi Akhir SCORM minimal 75/100 (Kriteria Ketuntasan Minimal).

Prasyarat Konsep & Fondasi Logika

1. Prinsip IPO

Input (Sensor) → Processing (ATmega328P) → Output (LED/Buzzer/Motor).

2. Logika Digital

Sinyal Biner HIGH (5V / True) & LOW (0V / False) serta manipulasi Analog (PWM).

3. Sintaks C++ Dasar

Struktur fungsi `setup()`, `loop()`, tipe data, variabel, dan percabangan `if-else`.

Komparasi: Single Board Computer (SBC) vs Mikrokontroler

Kategori Fitur Single Board Computer (mis. Raspberry Pi) Board Mikrokontroler (mis. Arduino Uno)
Sistem Operasi Menjalankan OS lengkap (Linux / Android) Tidaks membutuhkan OS (Bare-metal execution)
Fokus Utama Komputasi berat, GUI, Pemrosesan Gambar Kontrol I/O langsung, waktu nyata (real-time)
Konsumsi Daya Relatif Tinggi (5V - 3A+) Sangat Rendah (Sangat hemat energi)

Anatomi & Struktur Kode C++ Arduino Sketch

void setup() dieksekusi tepat satu kali saat board pertama kali dinyalakan atau di-reset untuk inisialisasi mode pin dan komunikasi Serial.

void loop() mengeksekusi instruksi di dalamnya secara terus menerus berulang selama listrik mengalir ke board.

pinMode(pin, mode): Menentukan peran pin sebagai INPUT atau OUTPUT.

digitalWrite(pin, val): Mengirimkan tegangan HIGH (5V) atau LOW (0V).

digitalRead(pin): Membaca nilai logika masukan digital (HIGH atau LOW).
